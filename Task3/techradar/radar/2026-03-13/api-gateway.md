# API Gateway

![stub](/images/api-gateway.svg)

[ADR](/adr/api-gateway.md)

**Бизнес-сценарии:**
- Подключение внешних партнёров (фармацевтика, электроника)
- Безопасный доступ к доменным сервисам
- Единая точка контроля и мониторинга

**Обоснование:**
Единая точка входа стандартизирует интеграции, упрощает управление доступом и позволяет быстро подключать новые сервисы без изменений в ядре системы.

**Риски:**
- Риск узкого места при неправильной настройке масштабирования
- Требует дисциплины версионирования API

**Владелец:** Integration Team

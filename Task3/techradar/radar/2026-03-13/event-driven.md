# Event-Driven Architecture

![stub](/images/event-driven.svg)

[ADR](/adr/event-driven.md)

**Бизнес-сценарии:**
- Асинхронная интеграция между доменами
- Обновление витрины данных в near real-time
- Снижение耦合ности между сервисами

**Обоснование:**
Домены общаются через события, не зная о получателях. Упрощает добавление новых потребителей данных без изменений в источниках.

**Риски:**
- Сложность отладки распределённых потоков
- Требует гарантии доставки и идемпотентности

**Владелец:** Архитектурный комитет

# CDC-пайплайны (Change Data Capture)

![stub](/images/cdc.svg)

[ADR](/adr/cdc-pipelines.md)

**Бизнес-сценарии:**
- Актуальность данных в витрине без нагрузки на источники
- Независимое развитие доменов
- Поддержка near real-time отчётности

**Обоснование:**
Минимальная нагрузка на операционные БД, автоматическое отслеживание изменений, возможность асинхронной обработки данных для аналитики.

**Риски:**
- Сложность отладки при ошибках в схемах данных
- Требует мониторинга лага репликации

**Владелец:** Data Team

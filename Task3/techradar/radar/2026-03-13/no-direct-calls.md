# Прямые вызовы между сервисами

![stub](/images/direct-calls.svg)

[ADR](/adr/no-direct-calls.md)

**Бизнес-сценарии:**
- Не рекомендуется для новых интеграций

**Обоснование:**
Создаёт жёсткую耦合ность, усложняет масштабирование и отказоустойчивость. Все новые интеграции только через API Gateway + Events.

**Риски:**
- Каскадные отказы
- Сложность версионирования
- Невозможность независимого деплоя

**Владелец:** Архитектурный комитет

# Cloud Lakehouse

![stub](/images/lakehouse.svg)

[ADR](/adr/cloud-lakehouse.md)

**Бизнес-сценарии:**
- Быстрая подготовка отчётности (секунды вместо часов)
- Портал самообслуживания для бизнес-аналитиков
- Масштабирование под новые бизнес-направления

**Обоснование:**
Разделение хранения и вычислений позволяет независимо масштабировать аналитические нагрузки. Поддержка структурированных и полуструктурированных данных упрощает интеграцию разнородных источников.

**Риски:**
- Требует переобучения команды
- Миграция данных из SQL Server 2008

**Владелец:** Data Team

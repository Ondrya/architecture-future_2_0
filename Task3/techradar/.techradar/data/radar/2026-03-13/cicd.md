# CI/CD Pipelines

![stub](/images/cicd.svg)

[ADR](/adr/cicd.md)

**Бизнес-сценарии:**
- Ускорение вывода изменений (time-to-market)
- Снижение рисков при деплое
- Независимые релизы доменов

**Обоснование:**
Автоматизация сборки, тестирования и развёртывания. Каждый домен может выпускать изменения без координации с другими.

**Риски:**
- Требует дисциплины написания тестов
- Начальные затраты на настройку

**Владелец:** DevOps Team
